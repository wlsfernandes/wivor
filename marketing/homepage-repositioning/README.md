# WiVor homepage marketing direction

This folder is the handoff for the next homepage iteration. Read these files in order:

1. [01-positioning.md](01-positioning.md) — audience, promise, and message hierarchy.
2. [02-homepage-brief.md](02-homepage-brief.md) — section order, copy direction, visual emphasis, and success criteria.
3. [03-local-ai-handoff.md](03-local-ai-handoff.md) — implementation scope and verification for the local AI.

The existing visual specification in `docs/frontend/00-frontend-guide.md` remains the design source of truth. This brief sharpens the homepage's marketing message within that system. It does not authorize invented claims, images, events, testimonials, or changes to purchase and privacy behavior.

## Next direction

Make the first screen say **what WiVor does, why an athlete should care, and how to start**. Show genuine photo proof early. Give photographers a separate, credible value proposition. Keep organizers easy to find without making three audiences compete in the hero.

The working event search is already present. The main opportunity is message hierarchy and product evidence, not a new site architecture.
